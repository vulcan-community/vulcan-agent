title: Quick start
description: Get Vulcan running in a few minutes.
---

This walks you from zero to "Vulcan replies to me" in about five minutes. You'll need [`uv`](https://docs.astral.sh/uv/) installed and, if you're going with Claude Code, the `claude` CLI logged in.

## 1. Install

```bash
git clone https://github.com/vulcan-community/vulcan-agent.git
cd vulcan-agent
uv sync --extra claude-code
```

Swap `claude-code` for `feishu` (or add both, comma-separated) depending on what you want to use.

## 2. Drop in a config

Create `~/.vulcan/vulcan.json` with the smallest thing that works:

```json
{
  "version": "0.1",
  "runtimes": {
    "claude-code": {
      "enable": true,
      "model": {
        "name": "claude-sonnet-4-5",
        "provider": "anthropic",
        "base_url": "",
        "api_key": ""
      }
    }
  },
  "channels": {}
}
```

Empty `api_key` and `base_url` means Vulcan will reuse your `claude` CLI login. If you'd rather point at a different endpoint, fill them in — see [Pick a model](/docs/runtimes).

## 3. Start it

```python
from pathlib import Path
from vulcan.gateway.gateway import Gateway

Gateway(home_dir=Path("~/.vulcan").expanduser()).start()
```

Save that as `run.py` and run `uv run python run.py`. Vulcan listens on `http://0.0.0.0:4000`.

## 4. Say hi

```bash
curl http://localhost:4000/v1/chat/completions \
  -H "Content-Type: application/json" \
  -H "X-Session-Id: default" \
  -d '{
    "model": "claude-code",
    "messages": [{"role": "user", "content": "hello"}]
  }'
```

You should get a reply back. Use the same `X-Session-Id` next time and Vulcan will pick up where you left off.

## Useful CLI commands

```bash
vulcan runtime list                 # see what's available
vulcan runtime install claude-code  # add a runtime's deps
vulcan runtime uninstall claude-code
```

## Make it your own

Vulcan's personality lives in `~/.vulcan/agent/IDENTITY.md`, `SOUL.md`, and `TOOL.md` — three plain Markdown files copied in on first start. Edit them to change how Vulcan introduces itself, what it sounds like, or what tools it leans on. Restart Vulcan to pick up your edits.
