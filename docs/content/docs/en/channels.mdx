A **channel** is just where you chat with Vulcan from. Today that's Feishu and the OpenAI-compatible HTTP API — meaning anything that speaks OpenAI (the official SDK, OpenWebUI, your own client, `curl`) can already talk to Vulcan with no extra setup.

## What's available

| Channel                | Status   | What you'd use it for                          |
| ---------------------- | -------- | ---------------------------------------------- |
| OpenAI-compatible HTTP | ✅       | Any OpenAI-style client, scripts, web UIs     |
| Feishu                 | ✅       | Chatting with your bot from Lark/Feishu       |
| Slack                  | coming soon | —                                          |
| Discord                | coming soon | —                                          |

## Set up Feishu

1. Create a bot in the Feishu developer console and grab its `app_id` and `app_secret`.
2. Add a `feishu` block to `~/.vulcan/vulcan.json`:

   ```json
   {
     "channels": {
       "feishu": {
         "enable": true,
         "runtime": "claude-code",
         "config": {
           "app_id": "cli_...",
           "app_secret": "..."
         }
       }
     }
   }
   ```

3. Restart Vulcan. That's it.

Now message your bot and Vulcan replies.

## What you'll see in the chat

Vulcan replies inside a single Feishu card that updates live as the model thinks. Everything from one of your messages lands in one card, so you can scroll back and see exactly what happened, end to end:

- **Streaming answer.** The reply text fills in word by word as the model writes it.
- **Quoted thinking.** When the model reasons before answering, you see its thoughts inline as a quoted block — no separate window, no hidden state.
- **Tool boxes.** When the model uses a tool (running a command, reading a file, searching the web), a collapsible panel pops in with the tool's name. Tap to open it and see what was passed in and what came back.
- **Reaction.** A quick emoji reaction lands on your message right away so you know Vulcan got it.

The whole reply is one card, one place to look. No "Vulcan is typing…" mystery — you can watch the chain of thought, peek inside any tool call, and see the final answer all at once.

## Picking which model replies

Each channel is tied to one runtime via `runtime` in the config above — that's the default for messages from this channel. If you want to switch mid-conversation, just send `/switch <runtime-name>` from the chat. See [Slash commands](/docs/commands).

## Adding a new chat app

Slack and Discord are on the roadmap. If you want to plug in something else right now, the existing Feishu integration in the [GitHub repo](https://github.com/vulcan-community/vulcan-agent/tree/main/vulcan/gateway/channels) is a working template — most of the work is just translating between the platform's events and Vulcan's chat format.
