Vulcan is a personal AI assistant you run yourself.

You talk to it from anywhere — a chat app on your phone, a web UI on your laptop, your terminal. Behind the scenes Vulcan can use Claude, OpenAI, or any other model you point it at, and you can switch between them mid-conversation. Your chats are saved on your own machine, never sent to a third party beyond the model you chose.

Set it up once, then forget about plumbing. Vulcan keeps your conversations organized, remembers context across days, and shows you what the model is thinking and which tools it's using — all in one tidy view.
