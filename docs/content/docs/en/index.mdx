Vulcan is the dispatch layer for **pluggable agent runtimes**. An "agent runtime" here is a full orchestration stack, not just an LLM — it's the model plus its tool surface, its sandbox, its reasoning loop. Claude Code reads files, edits code, runs shell, speaks MCP. OpenAI Codex does the same class of work. Google ADK brings its own orchestrator. Base OpenAI is plain Chat Completions — no built-in tools. Vulcan puts all of them behind one OpenAI-compatible API, keeps one JSONL transcript per session, and exposes one slash-command control plane. The same conversation can hop between runtimes mid-stream via `/switch`.

## What Vulcan is not

Not a model router. LiteLLM, OpenRouter and friends swap the underlying model weights behind a single chat-completion shape — same tools (none), different weights. Vulcan sits one level up: you swap the entire agent *stack* — different tool surfaces, different sandboxes, different reasoning loops, different persona injection hooks. Also not a new chat UI and not a prompt library — it speaks the OpenAI HTTP API so your existing clients (OpenWebUI, the `openai` SDK, `curl`, Feishu) just work.

## Supported agent runtimes

| Runtime       | Status    | What it is                                                   |
| ------------- | --------- | ------------------------------------------------------------ |
| `claude-code` | ✅        | Anthropic's Claude Code agent — files, shell, MCP, thinking. |
| `codex`       | ✅        | OpenAI Codex CLI — files, shell, MCP, web search.            |
| `base-openai` | ✅        | Any OpenAI-compatible Chat Completions endpoint. No tools.   |
| `google-adk`  | planned   | Google Agent Development Kit.                                |

Each runtime ships as an optional extra (`uv sync --extra claude-code`, `--extra codex`). Install only the ones you use.
