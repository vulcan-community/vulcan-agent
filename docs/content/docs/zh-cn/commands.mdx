---
title: 斜杠命令
description: 在任意聊天里查看和操控 Vulcan。
---

在任意聊天里发个斜杠命令,就能查看或改变 Vulcan 的状态——不用打开任何界面。把命令当普通消息发出去,Vulcan 直接在原地回你。

## 能做什么

| 命令                          | 做什么                                                                  |
| ----------------------------- | ----------------------------------------------------------------------- |
| `/help`                       | 列出当前所有可用的斜杠命令。                                            |
| `/version`                    | 显示当前 vulcan-agent 的版本号。                                        |
| `/switch <runtime>`           | 换接下来由哪个模型大脑回话。                                            |
| `/runtime`                    | 看现在有哪些模型可用——当前那个用 `*` 标出来。                          |
| `/sessions`                   | 看你所有过往对话,按最近活跃排序。                                      |
| `/session <name>`             | 翻某段对话的原始历史。                                                  |

`/session` 既接完整的 `<channel>/<session_id>`(直接从 `/sessions` 输出里拷),也接单独的会话 ID,前提是这个 ID 全局唯一。

## 聊到一半换模型

这条用得最多。比如你刚跟 Claude Code 聊了半天,下一个问题想换便宜点的模型:

```
/switch gpt-4o
```

Vulcan 回一句"Switched to runtime: gpt-4o",从这之后你的消息就走那个模型了。对话历史不丢——新模型从老模型停下的地方接着聊。

飞书里、`curl` 里、任意客户端里都一样。从 API 调用看是这样:

```bash
curl http://localhost:4000/v1/chat/completions \
  -H "Content-Type: application/json" \
  -H "X-Session-Id: default" \
  -d '{
    "model": "claude-code",
    "messages": [{"role": "user", "content": "/switch gpt-4o"}]
  }'
```

## 现在到底是哪个模型在回话?

API 请求按请求粒度挑模型——请求体里 `"model"` 写哪个就用哪个。Channel 消息(飞书这些)走当前默认值。`/switch` 改的是默认值。所以你在飞书里 `/switch`,下一条飞书消息就走新模型;但 API 请求里如果明确指了别的模型,该请求还是按它要的来。

## 写自己的命令

你可以加自己的斜杠命令——往 `vulcan/gateway/commands/` 里丢一份文件,写好返回内容,在 gateway 里注册一下。[GitHub 上现成的几个](https://github.com/vulcan-community/vulcan-agent/tree/main/vulcan/gateway/commands)就是模板,每个命令也就几行 Python。
