---
title: 快速上手
description: 从零跑通一次对话，再中途把 agent runtime 切了。
---

这个教程会带你装好 Vulcan、配一个 agent runtime、通过 OpenAI 兼容 HTTP API 发第一条消息、看一眼 session 流水，然后 —— 也是最关键的一步 —— 开第二个 runtime，在同一段对话里中途切过去，上下文不丢。

大概十分钟。按顺序来。

## 1. 前置条件

需要：

- Python **3.12+**
- 装好 [`uv`](https://docs.astral.sh/uv/)
- 下面任选其一：
  - `claude` CLI 已登录（用 `claude-code` runtime）
  - 一个 OpenAI 兼容的 API key 和 base URL（用 `base-openai`）
  - `codex` CLI 已登录（用 `codex` runtime）

挑你已经有凭据的那个。下面的步骤默认走 `claude-code`，第二个 runtime 用 `base-openai` —— 你可以自己替换。

## 2. 安装

```bash
git clone https://github.com/vulcan-community/vulcan-agent.git
cd vulcan-agent
uv sync --extra claude-code
```

extra 对应 runtime 和 channel：

- `claude-code` —— Claude Code runtime（装 `claude-agent-sdk`）
- `codex` —— Codex runtime（装 `openai-codex-sdk`）
- `feishu` —— 飞书 channel（装 `lark-oapi`）

一次装多个就逗号分隔：`uv sync --extra claude-code,codex`。

## 3. 写一份最小配置

Vulcan 读 `~/.vulcan/vulcan.json`。首次启动文件不存在会自动从模板拷一份，这里我们显式写一份，看看结构：

```json
{
  "version": "0.1",
  "runtimes": {
    "claude-code": {
      "enable": true,
      "model": {
        "model": "claude-sonnet-4-5",
        "base_url": "",
        "api_key": ""
      }
    }
  },
  "channels": {}
}
```

`base_url` 和 `api_key` 留空，runtime 会走本地凭据链 —— `claude-code` 就是用你 `claude` CLI 的登录态。

## 4. 启动 gateway

存成 `run.py`：

```python
from pathlib import Path

from vulcan.gateway.gateway import Gateway

Gateway(home_dir=Path("~/.vulcan").expanduser()).start()
```

跑起来：

```bash
uv run python run.py
```

Gateway 监听 `http://0.0.0.0:4000`，讲的是 OpenAI Chat Completions API。

## 5. 发第一条消息

开一个新终端，`curl` 一下：

```bash
curl http://localhost:4000/v1/chat/completions \
  -H "Content-Type: application/json" \
  -H "X-Conversation-Id: default" \
  -d '{
    "model": "claude-code",
    "messages": [{"role": "user", "content": "你好，你是谁？"}]
  }'
```

会拿到一个标准 `ChatCompletion` JSON，回复在 `choices[0].message.content`。两点要注意：

- `X-Conversation-Id: default` —— 随便什么字符串，只要下次复用就行。Vulcan 会在它底下分配一段 session（12 位十六进制随机 id），流水落在 `~/.vulcan/sessions/gateway/<session_id>.jsonl`。指针 `~/.vulcan/sessions/gateway/_conversations/default.json` 记着这个 conversation 当前挂在哪段 session 上 —— `/new` 只是把这个指针换到一段新 session，你传的 id 不变。
- `"model": "claude-code"` —— 这是 runtime 名字，不是模型名。模型名在 `claude-code` *里面*，配置里写了。

下一轮继续用同一个 conversation id，assistant 就能看到上一轮。

## 6. 看 session

Vulcan 把 slash command 当成一条合成的 user 消息，发法和普通消息一样：

```bash
curl http://localhost:4000/v1/chat/completions \
  -H "Content-Type: application/json" \
  -H "X-Conversation-Id: default" \
  -d '{
    "model": "claude-code",
    "messages": [{"role": "user", "content": "/sessions"}]
  }'
```

会列出当前 conversation 下的所有 session，每段一行，当前这段用 `*` 标出来。`/status` 显示解析到的 session id。`/session <session_id>` 打印指定 session 的流水。`/help` 列全部 command。

## 7. 关键一招 —— 对话中途切 agent runtime

停掉 gateway（`Ctrl+C`）。往 `~/.vulcan/vulcan.json` 里加第二个 runtime：

```json
{
  "version": "0.1",
  "runtimes": {
    "claude-code": {
      "enable": true,
      "model": {
        "model": "claude-sonnet-4-5",
        "base_url": "",
        "api_key": ""
      }
    },
    "base-openai": {
      "enable": true,
      "model": {
        "model": "gpt-4o-mini",
        "base_url": "https://api.openai.com/v1",
        "api_key": "sk-..."
      }
    }
  },
  "channels": {}
}
```

重新 `uv run python run.py`，然后在同一个 `default` conversation 上发：

```bash
curl http://localhost:4000/v1/chat/completions \
  -H "Content-Type: application/json" \
  -H "X-Conversation-Id: default" \
  -d '{
    "model": "claude-code",
    "messages": [{"role": "user", "content": "/switch base-openai"}]
  }'
```

从下一轮开始，同一段 conversation 当前 session 跑在 `base-openai` 上 —— 纯 Chat Completions、工具面不同、推理回路也不同。JSONL 流水还是那一份，继续往下长。想切回去就 `/switch claude-code`。想在保持 conversation id 不变的前提下清个场，发 `/new`：轮换到一段全新的 session，运行时绑定从上段 session 沿用过来。

这就是 Vulcan 最不一样的地方：不是换模型，而是换整个 agent runtime，在同一段 conversation 上。
