---
title: 挑一个模型
description: 选 Vulcan 用哪个 AI 大脑来思考。
---

**Runtime** 就是 Vulcan 用来思考的那个模型大脑。配置 Vulcan 时挑一个(或者几个),聊到一半还可以切换。Vulcan 还是那个 Vulcan,只是另一头换了模型。

## 现在支持哪些

| Runtime              | 状态        | 适合什么                                                              |
| -------------------- | ----------- | --------------------------------------------------------------------- |
| Claude Code          | ✅          | 全套编码 Agent 能力——跑工具、读文件、改代码                          |
| OpenAI 兼容          | ✅          | 任意聊天模型——ChatGPT、DeepSeek、Qwen、你自建的部署                  |
| Anthropic(直连)    | 规划中      | —                                                                     |
| Codex                | 规划中      | —                                                                     |
| Google ADK           | 规划中      | —                                                                     |

只要你的模型会说 OpenAI Chat Completions API,Vulcan 就已经能接上了——市面上多数云服务和自建方案都属于这一类。

## 怎么挑

- **Claude Code**——你想让 Vulcan 真的*帮你干活*:读文件、改代码、跑 shell 命令、上网查东西。开箱自带 Claude Code 全套工具。
- **OpenAI 兼容**——你只想要个聊天模型,或者你已经有现成账号/部署想接进来。ChatGPT、DeepSeek、任意带 OpenAI 风格接口的服务、自建在代理后头的模型都能用。

两个可以同时挂着,聊到一半 `/switch` 想切就切。

## 在 `vulcan.json` 里挑

打开 `~/.vulcan/vulcan.json`,在 `runtimes` 下面加一段。Claude Code 长这样:

```json
{
  "runtimes": {
    "claude-code": {
      "enable": true,
      "model": {
        "name": "claude-sonnet-4-5",
        "provider": "anthropic",
        "base_url": "",
        "api_key": ""
      }
    }
  }
}
```

`enable` 设成 `false` 就先放着不启动。改完重启 Vulcan 生效。

## 鉴权

两条路。

**用你已有的登录态。** `api_key` 和 `base_url` 留空,Vulcan 会复用你机器上现成的凭据。Claude Code 走的是你 `claude` CLI 已经登录的账号——你终端里能跑通 `claude` 命令,Vulcan 这边就能用。不用到处拷 key。

**填你自己的。** 把 `api_key` 和 `base_url` 填上,Vulcan 就走你指定的端点——公司代理、便宜点的服务、你自建的部署都行。一旦填了,Vulcan 完全照你写的来,不会再看本地 CLI 的设置。

## 加一个表里没列的模型

如果你那个模型会说 OpenAI API,基本上把 `base_url` 和 `api_key` 指过去就完事了——不用写代码。要接更特殊的东西,代码结构上加一个 runtime 也就一份 Python 文件加一段配置。GitHub 上 [`vulcan/runtime/`](https://github.com/vulcan-community/vulcan-agent/tree/main/vulcan/runtime) 目录里现成的几个可以当模板。
