---
title: 内部构造
description: Vulcan 怎么把你的聊天、模型和应用串起来。
---

Vulcan 站在你常用的聊天工具和你想用的 AI 模型中间。配置一次,它就帮你处理那些烦人的小事:保存每段对话、记住你上次聊到哪、把每条消息送到你挑的模型那边。

大概是这样:

```text
  你用的聊天入口                       你挑的模型
  (飞书、API、curl、         ┌──►   (Claude Code、ChatGPT、
   你自己的 UI)              │       DeepSeek、自建部署)
        │                    │
        ▼                    │
   ┌─────────────┐           │
   │   Vulcan    │───────────┘
   │  (邮局,负   │
   │   责派送)   │
   └─────────────┘
        │
        ▼
   你的对话记录,
   存在你自己机器上
```

## 一段对话,处处都能聊

你可以从手机上的飞书、终端里的 `curl`、或任何会说 OpenAI API 的工具跟 Vulcan 聊。底下是同一个 Vulcan,看的是同一份对话历史。早上在飞书里聊一半,下午回到笔记本继续,Vulcan 还记得你之前在说什么。

## 历史记录归你自己

每段聊天都是你机器上一份普通文本。不上云、不经第三方。只有你当下选中的那个模型能看到你正在发的这条消息,其它一切 Vulcan 都留在本地。想备份就拷文件夹,想翻两周前说过什么就直接打开文件读。

## 中途换模型,不丢上下文

Vulcan 可以同时挂着几个模型"大脑"。你选一个当默认,聊到一半想换,发个斜杠命令就换了——对话继续,只是回话的模型变了。某个问题想用 Claude 的编码能力,下一个问题想用便宜点的模型,都行。

具体支持哪些模型见 [挑一个模型](/docs/runtimes)。

## 一切都靠斜杠命令

不需要额外的管理界面。在任意聊天里发个斜杠命令,Vulcan 就在原地回你——看历史会话、切模型、查某条对话的原始内容,都不用打开别的东西。详见 [斜杠命令](/docs/commands)。

## 东西都放哪儿

Vulcan 把所有东西都放在你家目录下的一个文件夹里:

| 路径                              | 里面是啥                                |
| --------------------------------- | --------------------------------------- |
| `~/.vulcan/vulcan.json`           | 你的配置——模型、聊天入口、密钥         |
| `~/.vulcan/agent/`                | Vulcan 的人格设定(你可以改)           |
| `~/.vulcan/sessions/`             | 所有对话,一段一份文件                  |

里头的东西随便改、随便备份、随便删。重启后 Vulcan 会重新读配置。
