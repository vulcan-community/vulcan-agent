**可插拔运行时,统一 API。**

Vulcan Agent 位于客户端(OpenWebUI、`openai` SDK、`curl`、飞书等)和 Agent 运行时(Claude Code、OpenAI 兼容、Codex、Google ADK 等)之间。你在一份配置里挂运行时和 channel,Vulcan 负责会话流水和每一轮的分发。

编排有两个入口。`Gateway.invoke()` 把所有 yield 的 `SessionItem` 收齐,返回一条 `ChatCompletion` —— API 服务用这条路。`Gateway.invoke_stream()` 在运行时产出每个 `SessionItem` 时直接 yield —— channel 用这条路做渐进式渲染(比如飞书 CardKit 的渐进式卡片,文字、思考、工具调用边产出边落地)。

每个运行时只实现一个方法:`BaseRuntime.invoke(ctx) -> AsyncIterator[SessionItem]`。每个会话是一份 OpenAI `ConversationItem` 的 JSONL 流水。流水按来源隔离 —— API 请求落在 `channel_id="gateway"`,channel 消息落在 channel 的名字下。换运行时,流水继续。
