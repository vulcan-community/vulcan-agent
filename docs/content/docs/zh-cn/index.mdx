Vulcan 是**可插拔 agent runtime** 的 dispatch 层。这里的 "agent runtime" 不是单指一个 LLM，而是整套编排栈 —— 模型、工具面、沙箱、推理回路都包在里面。Claude Code 会读文件、改代码、跑 shell、讲 MCP；OpenAI Codex 做的是同一类活；Google ADK 自带一套 orchestrator；base OpenAI 就是纯 Chat Completions，没有内建工具。Vulcan 把它们全部挂在一套 OpenAI 兼容 API 后面，每个 session 留一份 JSONL 流水，一套 slash command 构成 control plane。每段 conversation 都有自己的 transcript，`/new` 在同一段 conversation 上起一份新的；同一段对话还能通过 `/switch` 中途切到另一个 runtime。

## Vulcan 不是什么

不是 model router。LiteLLM、OpenRouter 这类工具在同一个 chat-completion 接口下切换底层模型权重 —— 工具面是同一套（空的），换的是权重。Vulcan 往上高一层：切的是整个 agent *栈* —— 工具面不同、沙箱不同、推理回路不同、persona 注入钩子也不同。也不是新的聊天 UI，也不是 prompt 库 —— 它讲的是 OpenAI HTTP API，你现有的客户端（OpenWebUI、`openai` SDK、`curl`、飞书）直接能用。

## 支持的 agent runtime

| Runtime       | 状态     | 是什么                                                     |
| ------------- | -------- | ---------------------------------------------------------- |
| `claude-code` | ✅       | Anthropic Claude Code agent —— 文件、shell、MCP、thinking。 |
| `codex`       | ✅       | OpenAI Codex CLI —— 文件、shell、MCP、web 搜索。            |
| `base-openai` | ✅       | 任意 OpenAI 兼容 Chat Completions 端点，没有工具。          |
| `google-adk`  | planned  | Google Agent Development Kit。                             |

每个 runtime 是一个可选 extra（`uv sync --extra claude-code`、`--extra codex`）。按需装。
