**Channel** 就是你从哪里跟 Vulcan 聊天的地方。目前是飞书和 OpenAI 兼容的 HTTP API——意味着任何会说 OpenAI 的东西(官方 SDK、OpenWebUI、你自己写的客户端、`curl`)都能直接连上 Vulcan,不用再多配置什么。

## 现在能用的

| 渠道                   | 状态      | 适合什么                                       |
| ---------------------- | --------- | ---------------------------------------------- |
| OpenAI 兼容 HTTP       | ✅        | 任意 OpenAI 风格的客户端、脚本、网页 UI       |
| 飞书                   | ✅        | 在飞书里直接跟你的 bot 聊                     |
| Slack                  | 规划中    | —                                              |
| Discord                | 规划中    | —                                              |

## 接入飞书

1. 去飞书开放平台建一个机器人,拿到它的 `app_id` 和 `app_secret`。
2. 在 `~/.vulcan/vulcan.json` 里加一段 `feishu`:

   ```json
   {
     "channels": {
       "feishu": {
         "enable": true,
         "runtime": "claude-code",
         "config": {
           "app_id": "cli_...",
           "app_secret": "..."
         }
       }
     }
   }
   ```

3. 重启 Vulcan。完事。

接下来给你的 bot 发消息,Vulcan 就回了。

## 在聊天里你会看到什么

Vulcan 用一张飞书卡片回你,模型边想边更新。你这一条消息触发的所有东西都落在同一张卡片里,从头到尾翻回去就能看清楚发生了什么:

- **流式回答。** 模型边写,文字边一个个蹦出来。
- **引用块里的思考。** 模型先想再答的时候,你能在引用块里直接看到它在想什么——没有另起窗口、没有藏起来的状态。
- **工具盒子。** 模型用工具的时候(跑命令、读文件、上网搜),会插进来一个折叠面板,标题写着工具名。点开就能看到传了什么参数、返回了什么。
- **表情回应。** 你发完消息,Vulcan 立刻在你那条上贴个表情,告诉你它收到了。

整段回复就一张卡片,一个地方看。不会再纠结"Vulcan 在打字...." 是个啥状态——思考过程、每次工具调用的内幕、最终答案,你能一次全看到。

## 哪个模型来回话

每个 channel 都通过上面配置里的 `runtime` 字段绑一个模型——这个 channel 收到消息时默认用它。聊到一半想换,在聊天里发 `/switch <模型名字>` 就行。详见 [斜杠命令](/docs/commands)。

## 加一个新的聊天工具

Slack、Discord 在路上了。如果你现在就想接一个别的,GitHub 上 [现成的飞书集成](https://github.com/vulcan-community/vulcan-agent/tree/main/vulcan/gateway/channels) 就是一个完整的模板——主要工作就是把那个平台的事件翻成 Vulcan 的对话格式。
